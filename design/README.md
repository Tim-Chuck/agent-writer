# 蓝白界面目标图

三张图均用内置 ImageGen 单独生成。共同提示要求原创中文桌面小说工具，使用白色、冰蓝侧栏、深海军蓝文字、钴蓝操作色和细蓝灰分隔线，以宋体呈现正文。以《暮色来信》为示例项目，左栏固定保留作品、页面、章节和 API 设置。每张图使用以下场景提示。

- [写作台](./writing-desk.png) · 顶栏显示章节和保存操作。居中的站台章节，右侧显示模型、阅读范围、六类可勾选的创作材料、对话页签和底部输入框。
- [大纲看板](./outline-board.png) · 三幕、浅蓝圆点画布、场景卡片、章节链接和引用标签。右栏提供角色、道具、地点和组织设定，可拖入场景。
- [模型连接](./model-connection.png) · 左侧选择供应商，右侧显示官网、API 请求地址、默认模型、密钥字段和连接测试。
