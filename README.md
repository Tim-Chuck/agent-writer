# Agent Writer

Agent Writer 是一款中文小说工作台，支持文章导入与自动分章、可视化大纲、设定卡片和分章记忆。你可以连接自己的大模型，并为每次生成选择重点阅读的材料。首次启动时可以新建项目，也可以从已有文章导入。

## Windows 桌面版

用 Node.js 24 和 pnpm 11 在 Windows 上构建 x64 便携版：

```powershell
pnpm install --frozen-lockfile
pnpm build:win
```

构建完成后，双击 `dist` 目录中带版本号的 Agent Writer EXE。

桌面版把数据保存在 `%APPDATA%\Agent Writer\workspace`。首次从项目的 `dist` 目录打开时，会复制原浏览器版的项目和已保存的模型连接。两个版本之后分别保存各自的修改。

## 浏览器版

Windows 双击 **Start Agent Writer.cmd**。需要 Node.js 22 或更新版本，推荐 Node.js 24。首次启动会安装文件导入所需的依赖。启动后直接访问 [本机写作台](http://127.0.0.1:4317/)。

也可以在项目目录运行：

```sh
pnpm install --frozen-lockfile
pnpm start
```

## 开始写作

1. 在「API 设置」选供应商，按「获取密钥」取得 API Key，填入后测试并保存。可填写供应商的基础地址或完整请求地址。自定义支持 OpenAI 兼容 Chat Completions、OpenAI Responses 和 Anthropic Messages，本机 HTTP 模型可留空密钥。
2. 在「设定卡片」维护角色、道具、地点和组织。在「故事大纲」用三幕看板组织场景，从右栏拖设定到场景，或者在场景编辑窗口勾选。场景可跨幕移动、重新排列或关联正文。长线规划写在看板下方的「创作规划」。
3. 在「参考资料」拖入文件或多选上传。支持 TXT、Markdown、CSV、TSV、JSON、JSONL、HTML、XML、DOCX、PDF、EPUB、ODT。单文件上限 25 MB，提取上限 200 万字符。PDF 读取已有文字层。导入后能预览提取的文字。
4. 回到写作台，在「阅读范围」整类勾选或逐项选择前文、设定、规划、大纲、记忆、参考资料。当前章会自动带入。重点条目优先带入正文或摘录，其他条目在预算内带入短摘要。生成后可以展开「本次阅读范围」查看实际使用量。
5. 在助手底部选择「写正文」「理情节」或「查逻辑」，发送请求。回复可以复制或写入章节。正文编辑自动保存，也支持 Ctrl+S。
6. 要导入已有文章，在空白工作区或侧栏「章节」选择「导入文章」。预览会按常见中英文章节名、Markdown 标题或文档标题分章。可以改为整篇一章，再追加到当前项目或新建项目。
7. 要删除项目，在侧栏切换到该项目，点项目名称旁的删除按钮并确认。

## 记忆与数据

「记忆」按项目保存正文、设定、规划、场景和导入文字的快照。默认开启按章节保存和每 7 天保存一次，可随时手动存档，也可启用按累计改动字数存档。新建章节，以及识别到「开始下一章创作」一类明确请求时，会检查章节记忆。定期检查在本机服务运行时执行，服务重新启动后补存已经到期的记忆。

浏览器版的作品和模型连接配置保存在项目目录的 `.writer-data` 中。保存的密钥在本机加密后写盘。备份时保留整个数据目录。生成请求会把本次上下文和提示发给你选择的供应商。

可使用环境变量 `AGENT_WRITER_PORT` 和 `AGENT_WRITER_DATA_DIR` 指定本机端口或数据目录。
