# Agent Writer

Agent Writer 是一款中文小说工作台，支持文章导入与自动分章、可视化大纲、设定卡片和分章记忆。你可以连接自己的大模型，并为每次生成选择重点阅读的材料。首次启动时可以新建项目，也可以从已有文章导入。

## Windows 桌面版

用 Node.js 24 和 pnpm 11 在 Windows 上构建 x64 便携版：

```powershell
pnpm install --frozen-lockfile
pnpm build:win
```

构建完成后，双击 `dist` 目录中带版本号的 Agent Writer EXE。

桌面版把数据保存在 `%APPDATA%\Agent Writer\workspace`。首次从项目的 `dist` 目录打开时，会复制原浏览器版的项目和已保存的模型连接。两个版本之后分别保存各自的修改。

## 浏览器版

Windows 双击 **Start Agent Writer.cmd**。需要 Node.js 22 或更新版本，推荐 Node.js 24。首次启动会安装文件导入所需的依赖。启动后直接访问 [本机写作台](http://127.0.0.1:4317/)。

也可以在项目目录运行：

```sh
pnpm install --frozen-lockfile
pnpm start
```

## 开始写作

1. 在「API 设置」选供应商，按「获取密钥」取得 API Key，填入后测试并保存。可填写供应商的基础地址或完整请求地址。自定义支持 OpenAI 兼容 Chat Completions、OpenAI Responses 和 Anthropic Messages，本机 HTTP 模型可留空密钥。
2. 在「设定卡片」维护角色、道具、地点和组织。在「故事大纲」用三幕看板组织场景，从右栏拖设定到场景，或者在场景编辑窗口勾选。场景可跨幕移动、重新排列或关联正文。长线规划写在看板下方的「创作规划」。
3. 在「参考资料」拖入文件或多选上传。支持 TXT、Markdown、CSV、TSV、JSON、JSONL、HTML、XML、DOCX、PDF、EPUB、ODT。单文件上限 25 MB，提取上限 200 万字符。PDF 读取已有文字层。导入后能预览提取的文字。
4. 回到写作台，在「阅读范围」整类勾选或逐项选择前文、设定、规划、大纲、记忆、参考资料。逐项选择的材料优先保留全文，旧章通过剧情要点和原文检索补充。可开启「深读写作」增大阅读额度和等待时间，在「本次阅读范围」查看全文、节选和召回出处。可在「API 设置 → 高级设置」填写模型公布的上下文窗口，应用会保守估算阅读额度并为生成预留 token。
5. 在助手底部选择「写正文」「理情节」或「查逻辑」，发送请求。点击「附件」或把文件拖进聊天框，可添加最多 5 份文字文件，格式和大小限制与参考资料相同。附件在发送时提供给模型，供当前对话使用。长文件可由助手分页阅读。回复可以复制或写入章节。正文编辑自动保存，也支持 Ctrl+S。
6. 要导入已有文章，在空白工作区或侧栏「章节」选择「导入文章」，再选文件或把文件拖到「文章文件」区域。预览会按常见中英文章节名、Markdown 标题或文档标题分章。可以改为整篇一章，再追加到当前项目或新建项目。
7. 在侧栏用项目名称旁的铅笔按钮重命名项目，或用垃圾桶按钮删除项目。章节列表也有删除按钮。删除最后一章时，项目会新建一章空白正文。
8. 明确要求助手生成多章正文时，应用按章写入并打开首章。已有正文的项目会追加章节，刚建的空白项目会使用第一章占位。若只想在对话里看草稿，请说明「只在对话里输出」。
9. 侧栏「章节」旁的下载图标可导出 TXT。可以导出全书，或勾选任意章节，文件按原书章节顺序保留标题与正文。

## 让助手操作工作区

连接模型后，可以在对话里直接要求助手实际操作。例如「新建一章叫雨夜，把下面这段写进去，再保存一份记忆」。助手可以操作项目、章节、设定卡片、故事大纲、参考资料、文章导入、记忆、模型连接和阅读范围。每次对话结束后可以展开「工具记录」核对结果。

删除或覆盖正文等操作会在对话中等待确认。助手发出文件请求时，可以点击「选择文件」，也可以将文件拖到该条请求上。模型连接需要新密钥时，可在应用提供的密码框输入。工具调用支持 Chat Completions、Responses 和 Anthropic Messages。模型服务拒绝原生工具请求时，应用会尝试通过结构化文本传递工具调用。

发出的消息、助手回复和工具记录会自动保存在本机，按项目和章节恢复。再次打开有记录的章节时会显示「对话」。写作时优先带入最近三轮成功对话，也可以检索同一章较早的讨论和草稿。重启后可查看附件名称，需要继续读取附件原文时请重新添加文件。退出前尚未确认的工具操作需要重新发起。

## 记忆与数据

「记忆」按项目保存正文、设定、规划、场景和导入文字的快照。默认开启按章节保存和每 7 天保存一次，可随时手动存档，也可启用按累计改动字数存档。新建章节，以及识别到「开始下一章创作」一类明确请求时，会检查章节记忆。定期检查在本机服务运行时执行，服务重新启动后补存已经到期的记忆。

在「记忆」开启「保存记忆时识别」后，每次保存快照都会由当前模型在后台分析新增或有改动的章节。结果在「AI 设定卡」里按角色、道具、地点和组织查看，每项带有来源章节和原文依据。作者手动维护的设定卡片独立保存。需要把 AI 设定作为写作参考时，可以在「阅读范围」勾选相关记忆。

在「记忆」开启「提取剧情要点」后，当前模型会读取已有正文，之后随记忆增量处理新增或修改的章节。事件、状态变化、人物知情和伏笔都附有可核对的原文，点击「查看正文位置」可回到对应片段。改稿后，旧版要点退出当前稿件的自动召回，保存记忆后更新。助手也可以直接检索前文和参考资料，按章节 ID 与偏移分页核对原文。

浏览器版的作品和模型连接配置保存在项目目录的 `.writer-data` 中。保存的密钥在本机加密后写盘。备份时保留整个数据目录。生成请求会把本次上下文和提示发给你选择的供应商。

可使用环境变量 `AGENT_WRITER_PORT` 和 `AGENT_WRITER_DATA_DIR` 指定本机端口或数据目录。
